# Код адаптивного обновления прогноза

Реализация находится в `src/adaptive_diffusion`. Основная задача — обновить
незавершённый диффузионный прогноз после раскрытия дополнительных исторических
наблюдений, выбрав глубину повторного зашумления при заданном бюджете.

## Модель и выбор глубины

`model.py` содержит самостоятельную архитектуру для обучения с нуля:

- GRU кодирует историю каждого участника вместе с масками доступных измерений;
- социальный энкодер объединяет представления соседей;
- Transformer предсказывает шум в будущей траектории;
- условие денойзера включает новый контекст, старый контекст и их направленную
  разность. При обычной генерации оба контекста совпадают.

Это компактная модель, вдохновлённая постановкой
[MID](https://github.com/Gutianpei/MID), а не воспроизведение MID. Сторонние
исходники, веса и данные в репозиторий не включены. Обучение использует
[DDPM](https://arxiv.org/abs/2006.11239), сэмплирование — детерминированный
[DDIM](https://arxiv.org/abs/2010.02502) с косинусным расписанием.

Обучение денойзера объединяет обычную задачу предсказания шума и вспомогательную
задачу исправления состояния после смены контекста. Для второй задачи один шаг
со старым контекстом создаёт промежуточное состояние; модель по новому контексту
восстанавливает целевую чистую траекторию. Параметр `training.switch_weight`
управляет весом этого слагаемого; значение `0` задаёт абляцию без него.
После обучения модели энкодер и денойзер заморожены при построении целей MLP.

`selector.py` содержит MLP с двумя скрытыми слоями 128 и 64. Её вход:

```text
[h_old, h_new, h_new - h_old, abs(h_new - h_old),
 logSNR / 10, budget / 64,
 old_available_fraction, new_available_fraction, revealed_fraction,
 old_mean_observation_time, new_mean_observation_time, cosine_similarity]
```

MLP оценивает ожидаемый Energy Score пяти действий и выбирает минимальную оценку
для всего ансамбля. Истинное будущее требуется только для получения обучающих
целей и последующей оценки. Признаки MLP не содержат будущих координат.

| Действие | Обновление |
|---|---|
| `continue` | Продолжение с нового контекста без дополнительного шума |
| `fixed25` | Повторное зашумление на 25% пути к максимальному шуму в logSNR |
| `fixed50` | То же, 50% |
| `fixed75` | То же, 75% |
| `restart` | Независимый гауссов шум, полный отказ от промежуточного состояния |

В `diffusion.py` повторное зашумление реализовано через точный условный
прямой переход VP-процесса. Если текущее время — `s`, выбранное — `r >= s`, то:

```text
ratio = alpha_bar(r) / alpha_bar(s)
z_r = sqrt(ratio) * z_s + sqrt(1 - ratio) * epsilon
```

Действие `restart` получает независимый шум, а не этот переход. Глубина задаёт
интервал уровней шума; бюджет задаёт число DDIM-шагов на выбранном интервале.
Обратный процесс завершается чистой оценкой при `t=0`.

## Установка

Из корня репозитория, Python 3.9 или новее:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[test]'
adaptive-diffusion --help
```

Параметры задаются в `configs/default.json`. Для воспроизводимой среды нужно
сохранить установленные версии пакетов командой `python -m pip freeze`.
По умолчанию используется CPU; устройство задаётся полем `device`.

## Данные

Синтетический генератор создаёт независимые сцены с двумя вариантами поворота.
Положение соседей влияет на вероятность выбора варианта. Старый контекст
содержит часть истории, новый раскрывает дополнительные исторические измерения.
Сцены детерминированно распределяются между train/val/test.

```bash
adaptive-diffusion synthetic --scenes 300 --output data/synthetic
```

Для ETH/UCY принимаются текстовые файлы с четырьмя колонками:
`frame pedestrian_id x y`, координаты — в метрах. Данные приобретаются отдельно
с соблюдением условий их владельцев. Pickle-файлы из MID напрямую не читаются.
Пример манифеста — `configs/eth_ucy_manifest.example.json`.

```bash
adaptive-diffusion prepare-eth \
  --raw data/raw/eth_ucy \
  --manifest configs/eth_ucy_manifest.example.json \
  --frame-step 10 --stride 10 --agents 8 \
  --output data/eth_ucy
```

`frame-step` — разность номеров соседних выбранных кадров, а не секунд.
Его следует согласовать с нумерацией исходных файлов. Пример манифеста задаёт
один holdout: ETH — test, Hotel — val, остальные — train. Это не готовый
пятифолдовый ETH/UCY benchmark. Для других фолдов нужны отдельные манифесты,
контрольные точки и результаты. Связанные записи одного физического места
следует объединять одним `scene`, чтобы окна не пересекали границы выборок.

Преобразователь центрирует все координаты относительно последнего известного
положения целевого пешехода. Прогнозируемый горизонт фиксирован. Новые измерения
относятся только к истории: будущие кадры не раскрываются в условие.
Порядок кандидатов в соседи фиксирован по ID, чтобы скрытые координаты не влияли
на выбор top-k. Это простое ограничение подготовки данных; при малом `agents`
часть взаимодействий может быть потеряна.

NPZ-файлы содержат:

| Поле | Форма |
|---|---|
| `positions` | `[N, agents, observations, 2]`, float32 |
| `old_mask`, `new_mask` | `[N, agents, observations]`, bool |
| `future` | `[N, horizon, 2]`, float32 |
| `scene` | `[N]`, строковые идентификаторы независимых сцен |

Маска `old_mask` — подмножество `new_mask`. Последняя позиция цели доступна
в обоих контекстах. Разделение выполняется до нарезки окон; загрузчик проверяет
отсутствие общих сцен у train, val и test.

## Обучение и сравнение

Команды выполняются последовательно; пути можно заменить на ETH/UCY.

```bash
adaptive-diffusion train-diffusion \
  --data data/synthetic --output artifacts/diffusion.pt

adaptive-diffusion make-labels \
  --data data/synthetic --checkpoint artifacts/diffusion.pt \
  --output artifacts/labels

adaptive-diffusion train-selector \
  --labels artifacts/labels --checkpoint artifacts/diffusion.pt \
  --output artifacts/selector.pt

adaptive-diffusion calibrate \
  --labels artifacts/labels --output artifacts/calibration.json

adaptive-diffusion evaluate \
  --data data/synthetic --checkpoint artifacts/diffusion.pt \
  --selector artifacts/selector.pt --calibration artifacts/calibration.json \
  --output results/comparison.csv

adaptive-diffusion summarize \
  --results results/comparison.csv --output results/summary.json
```

Построение целей перебирает пять действий из одного исходного ансамбля для
каждого момента поступления наблюдений, бюджета и seed. Train используется для
обучения MLP, val — для выбора её контрольной точки и настройки базовых правил.
Test используется командой `evaluate`. Хеш контрольной точки связывает цели,
MLP и пороги с конкретным денойзером; несовпадение вызывает ошибку.

Сравниваемые методы:

- пять отдельных действий;
- `fixed` — лучшее постоянное действие, выбранное на val;
- `adaptive` — обученная MLP;
- `l2`, `cosine` — расстояние контекстов с порогами, подобранными на train/val;
- `probe` — эвристика по расхождению предсказанного шума под старым и новым
  контекстом. Это диагностический baseline, не воспроизведение Falcon или RDM.
  Его два вызова денойзера вычитаются из бюджета. При бюджете <=2 он продолжает
  генерацию без дополнительных проб. Пороги `[0.1, 0.25, 0.5, 1]` фиксированы.

Начальный ансамбль, количество прогнозов, момент прерывания и случайный шум
попарно одинаковы для методов. Для каждого обновления доступно ровно `B` вызовов
денойзера над всем ансамблем. CSV дополнительно содержит число обработанных
отдельных траекторий, стоимость префикса, число диагностических проб и общую NFE.
Время обновления включает выбор действия, пробы и расшумление с синхронизацией
ускорителя; общий энкодер, исходный префикс и вычисление метрик в него не входят.
Первый вызов может включать прогрев, поэтому время следует интерпретировать
вместе с NFE; порядок методов циклически меняется между окнами.

Основная метрика — Energy Score по вектору всей траектории. Используется
U-оценка попарного члена без диагонали, поэтому конечная оценка может быть
отрицательной. Дополнительно сохраняются Variogram Score с показателем 0.5,
minADE/minFDE, средняя ADE, разнообразие, маргинальное покрытие и ширина
90%-интервалов. Покрытие координат не означает одновременного покрытия всей
траектории. Доверительные интервалы в сводке строятся bootstrap по сценам,
а не по зависимым перекрывающимся окнам. Для утверждений о различиях методов
следует анализировать попарные различия по сценам, а не только их отдельные CI.

Конфигурация охватывает один приход контекста внутри незавершённой генерации.
Разные seed в `experiment.seeds` меняют ансамбли при фиксированных весах;
для оценки вариативности обучения нужны отдельные обучения с разными `seed`
верхнего уровня. Число эпох, размеры ансамблей и бюджеты — настраиваемые
параметры протокола, а не установленные оптимальные значения.

## Проверки кода

```bash
python -m pytest -q
```

Проверки охватывают условное повторное зашумление, независимый перезапуск,
точное число вызовов денойзера, неизменность сохранённого состояния, маскировку
скрытых наблюдений, конечность градиентов, сериализацию весов, расчёт метрик,
проверку разделения сцен и подготовку короткой искусственной записи ETH/UCY.
